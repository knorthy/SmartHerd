Scope: the whole SmartHerd app (src/app). Mode: Operate. Platform: Android first, iOS same look.

Audience/job: cooperative members weighing goats in daylight; read the herd's readiness for sale, run a weighing, save it, follow growth.

Chosen direction: Extension Bulletin world (user's pick), with the Weigh Slip & Sale Board organisation for Home (user's explicit fusion).

## Direction contract

THESIS: The app is a printed livestock technical bulletin brought to life: white page, deep-green second colour, hairline rules, tabular figures. It refuses the green-header-plus-cards farm template.

OWN-WORLD: Paper white #FFFFFF, ink #111614, secondary ink #4A5651, rule #D9E4DE, bulletin green #0F5C45 (second colour: primary action, dimension lines, selection), green tint #E7EFEA, ochre #9A6212 / tint #F6EBD3 reserved for "at sale weight". Hairline 1px rules, no shadows, no cards; system sans, tabular numerals, sentence-case labels; figure captions "Fig. 1 — Side view".

STORY: Open the app → see which goats are ready or nearest sale weight → New weighing → stage + two photos + distance → Estimate → result plate with measured figures → Save Goat → the goat's record grows.

FIRST VIEWPORT: Home = Sale board. Title "Sale board" + offline/sync line; a ruled table (Tag · Goat · kg · Status) ranked by days to the 30 kg sale weight, ready rows on an ochre tint; under it the last weighing as a segmented slip; a full-width green "New weighing" button pinned above the tab bar. Tabs: Board, Goats, Co-op.

FORM: Extension Bulletin, my pick (position 1 on the ordered list), fused with the dealt challenger vernacular-ephemera-boarding-pass-and-gate-board for Home. seed:cd0650fa059fcfd0. Signature move: the result screen's photos set as bulletin figures with green dimension lines (body length, chest height on side view; chest width on top view) labelled in cm, with zoom/rotate/pan.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
